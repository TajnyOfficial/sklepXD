◆ calculateInvoiceData

export const calculateInvoiceData

Moduł narzędziowy do kalkulacji faktur VAT (zgodnie z polskimi przepisami prawnymi).

Zastosowanie: Zawiera logikę matematyczną i finansową niezbędną do przeliczania wartości netto/brutto i grupowania ich na poprawne, wymagane w Polsce "podsumowania VAT" per stawka. Przelicza pozycje faktury, dodaje wartości cząstkowe dla poszczególnych wierszy i tworzy globalne podsumowanie wartości podzielone na poszczególne stawki VAT.

Parameters
{Object}invoice - Zarys obiektu faktury z danymi nagłówkowymi
{Array}invoice.items - Lista surowych pozycji faktury (np. { qty, unitPriceNet, vatRate })
Returns
{Object|null} Wzbogacony obiekt faktury zawierający vatSummary i globalne total

◆ formatPDFCurrency

export const formatPDFCurrency
Initial value:
= (val) => {
return (val || 0).toLocaleString('pl-PL', {
minimumFractionDigits: 2,
maximumFractionDigits: 2
}) + ' PLN';
}

Formatuje liczbę do postaci walutowej przystosowanej pod widok do wydruku (PDF). Wymusza wyświetlanie dwóch miejsc po przecinku bez względu na wartość zerową groszy.

Parameters
{number}val - Wartość kwotowa
Returns
{string} Sformatowany ciąg znaków, np. "1 500,00 PLN"
